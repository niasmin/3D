# ขุนพลสามก๊ก (Cocos Creator)

โครงโปรเจกต์สำหรับย้ายเกมต้นแบบบนเว็บไปเป็นเกมมือถือด้วย Cocos Creator 3.8 ตรรกะเกมทั้งหมดใช้ร่วมกันได้ทันที ส่วนหน้าจอต้องสร้างใหม่ใน editor

## โครงสร้าง
| โฟลเดอร์ | เนื้อหา |
| --- | --- |
| `assets/scripts/core/game-data.ts` | ตรรกะเกมล้วน (ไม่มี DOM): ขุนพล 61 คน ระบบต่อสู้ สกิล 5 แบบ มิตรภาพ อุปกรณ์ สัตว์เทพ หอท้า ประลอง เนื้อเรื่อง 8 บท กิจกรรมรายสัปดาห์ และภาพ placeholder แบบ SVG |
| `assets/scripts/core/state.ts` | รูปแบบเซฟและเกมเริ่มต้น |
| `assets/scripts/components/` | ตัวอย่าง component: `GameManager` (เซฟ), `HeroCard` (การ์ด), `BattleView` (เล่นการต่อสู้จากผลของ `simulate`) |
| `assets/resources/heroes/` | ที่วางภาพตัวละครจากนักวาด ตั้งชื่อตามคู่มือศิลป์ (`guanyu_card.png` ฯลฯ) |
| `art/prompts.csv` | prompt สร้างภาพของขุนพลทุกคน |
| `tests/` | เทสต์ตรรกะเกม |

## เริ่มใช้
1. ติดตั้ง Cocos Creator 3.8 จาก Cocos Dashboard แล้วเลือก Open Project ที่โฟลเดอร์นี้
2. สร้าง scene แรก ใส่ node ที่มี `GameManager`
3. สร้าง prefab การ์ดที่มี `HeroCard` และ scene ต่อสู้ที่มี `BattleView` (ช่องผู้เล่น 5 จุด ช่องศัตรู 5 จุด)
4. วางภาพตัวละครใน `assets/resources/heroes/`

## เทสต์
ต้องใช้ Node 22.6 ขึ้นไป: `npm test`

## สิ่งที่ยังต้องทำ
- หน้าจอทุกหน้า (เมือง ขุนพล อัญเชิญ จัดทัพ ด่าน ฯลฯ) ดูต้นแบบจากเกมบนเว็บ
- เอฟเฟกต์และเสียงในการต่อสู้ (ต้นแบบอยู่ในฟังก์ชัน `fx`, `fly`, `sfx` ของเกมบนเว็บ)
- `game-data.ts` ยังปิดการตรวจ type (`@ts-nocheck`) เพราะย้ายมาจาก JavaScript ตรง ๆ ควรเติม type ทีละส่วน
- ระบบออนไลน์: เวอร์ชันเว็บใช้ฐานข้อมูลของ claude.ai ถ้าเป็นแอปมือถือต้องมีเซิร์ฟเวอร์ของตัวเอง (เช่น Supabase หรือ Firebase)
- component ทั้ง 3 ตัวยังไม่ได้ทดสอบใน Cocos Creator จริง
